# X Banners

A responsive gallery of X profile headers with category filters, keyword search, profile previews, and 1500 × 500 downloads.

## Run locally

Open `index.html` in a browser. The page uses Tailwind's CDN and Unsplash-hosted sample images.

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site. No build command is required; use the repository root as the project directory.
